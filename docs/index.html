      How well it works

      Every dot is one of test X-rays the model never saw, placed by its fracture score. Drag the threshold: moving it left catches more fractures but raises more false alarms.

      ROC curve

      Each point on the curve is one threshold: how many fractures are caught (up) against how many normal X-rays are flagged (right). The dot is the current threshold. A useless model follows the dashed diagonal; the area under the curve is (0.5 = guessing, 1 = perfect).

      The default threshold, , was chosen on separate validation images so that, with 95% confidence, at least 85% of fractures are caught.
